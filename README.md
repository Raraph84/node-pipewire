# node-pipewire

Node.js bindings for [PipeWire](https://pipewire.org/) using [koffi](https://koffi.dev/) FFI.

## Requirements

- Node.js
- PipeWire (`libpipewire-0.3.so.0`)

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

## Usage

See [`examples/event-registry-sync.ts`](examples/event-registry-sync.ts) for a complete example:

```bash
npx tsx examples/event-registry-sync.ts
```
